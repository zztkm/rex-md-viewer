# 検証手順

## 自動テスト

```bash
make check test
```

Go のテストで以下を検証する。

- CLI の既定値、排他的なオプション、値の検証、`--` 以降のパス。
- 表示倍率の境界値、不正値、CLI と環境変数の優先順位、分割先への正確な引き渡し、既存ペインの倍率を変えないこと。
- 倍率が不正ならファイルを読まず、Rex を呼ばず、既存の PNG を変更しないことと、描画しないコマンドには影響しないこと。
- PNG の横幅と倍率 `1` の既存描画を維持し、拡大時に文字、折り返し、チェックボックスが大きくなり、小さなローカル画像を拡大しないこと。
- `0.5`、`1`、`1.2`、`4` の倍率で、疑似端末へ実際に送信した PNG が期待する描画結果と一致すること。
- スクロール、ページ移動、セル高の変更、リサイズ、保存、再読み込み後も指定倍率を保つことと、倍率適用後に下限補正しないこと。
- 縮小と拡大後のリンク操作、進行中のドット表示の合成結果。
- フォントの優先順（CLI、環境変数、既定候補、同梱 Go フォント）、読み込み失敗時のフォールバック、相対パスの解決。
- 日本語の文字単位のフォールバック、本文と太字の独立した選択、選択済みフォント設定の分割先への引き継ぎ。
- Skill の埋め込み内容、配置、再実行、上書きの拒否と `--force`。
- 同じサイズと更新時刻での変更検知、rename による置換、削除と復旧、シンボリックリンクの差し替え。
- 連続変更の待機時間と最大待機時間。
- Markdown の対応要素、日本語、コードの空白、狭い幅、表、ローカル画像、GIF の先頭フレーム、画像の読み込み失敗。
- コードブロックの言語と別名による色分け、ライトとダークの配色、端末背景による配色選択。
- ハイライトによって文字、空白、改行、字形、折り返し位置が変わらないことと、PNG 出力の再現性。
- 言語指定なし、未対応の言語、大きなブロック、構文解析の失敗時に単色表示を維持すること。
- インラインコード、インデントによるコードブロック、生の HTML をハイライトしないこと。
- リストのマーカーと本文の間隔、チェックボックスの左位置、入れ子、複数桁の番号、折り返しと後続段落の配置。
- TODO の角丸、チェックマーク、完了本文の色、専用の文字サイズと行間、通常のリストを変更しないこと。
- TODO の装飾と子項目の状態の維持、チェックボックスのスクロール時の切り取り、明るいアクセント色でのコントラスト。
- `[~]` の認識範囲と、コード、エスケープ、後続段落、通常の本文を誤認識しないこと。
- 作業中の枠と背景、3点の配置、明るさの周期、子項目への背景の非継承。
- 小さなアニメーション画像を合成した結果が全体描画と一致すること、画面外で更新しないこと、PNG 出力の再現性。
- リモート画像を取得しないこと、HTML をソースとして表示すること。
- 文書全体の画像と、同じ範囲だけを描画した画像の一致。
- 入力 Markdown と同じファイル、ハードリンク、シンボリックリンクへの PNG 出力の拒否。
- 分割表示の同時起動と再利用、終了、別のプログラムを閉じないこと。
- Rex CLI の接続失敗時に状態を失わないことと、split の応答失敗時の起動済みペインの回収。
- Kitty の画像送信と配置、分割されて届く端末応答、色の解析、端末制御文字の除去。
- HTTP/HTTPS の URL の検証、Markdown のリンク先とクエリとフラグメントの保持、対象外のリンクの除外。
- 折り返し、表の配置、TODO の装飾、同じ端末セル内の隣接リンクとクリック領域の一致。
- ピクセル座標、Cmd キーの押下と解放、キーボードの既存操作、分割されて届く入力シーケンス。
- 疑似端末でのリンク先の記録、通常クリックの無視、ドラッグ、フォーカス喪失、更新やリサイズ中のクリック取り消し。
- macOS の Rex で取得した実入力列の再生による、マウス解放前の重複したフォーカス取得通知でクリックを取り消さないことと、フォーカス喪失時には状態を消去すること。
- ブラウザ起動の失敗からの継続、起動処理中の終了、入力モードの復元、非対応の端末でリンク操作を無効にすること。

リンクの疑似端末テストは `scripts/test_links_terminal.py` から Go のテスト用 Viewer を起動する。
ブラウザ起動処理を記録用の関数に置き換えるため、実際のブラウザは起動せず、リンク先へも通信しない。
この置き換えはテスト実行ファイルだけに存在し、通常のバイナリに起動処理を差し替える環境変数は設けない。

ペイン管理の Go テストは Rex CLI をテスト用プロセスに置き換えて実行する。
実際の Rex との連携は別のスモークテストで確認する。
描画テストは日本語フォントがない場合にスキップするため、テストログを確認する。
CI では Linux に Noto Sans CJK を導入し、macOS ではシステムフォントを使用する。

### 倍率の fuzz テスト

```bash
go test -run '^$' -fuzz '^FuzzScaleOptions$' -fuzztime=10s
```

任意の文字列を `--scale` に渡し、有限で範囲内の数値だけを受け付けることを検査する。
これは入力の性質を調べるテストであり、すべての入力に対する形式的な証明ではない。

倍率の疑似端末テストは `scripts/test_scale_terminal.py` を Go のテストから起動する。
リンクの疑似端末テストは `0.5`、`1`、`4` の倍率で入力列を再生する。

## 疑似端末での確認

```bash
make smoke
```

Python 3 の標準ライブラリで疑似端末を作り、ビルドしたバイナリを実行する。
Rex は必要ないが、日本語フォントは必要とする。

- Kitty の問い合わせに応答して表示を開始し、送信された PNG が文書全体ではなく表示領域の大きさであることを確認する。
- TODO を含む文書でリサイズ、スクロール、Markdown の変更、削除、再作成、手動更新、テーマ変更を実行する。
- 端末の前景色と背景色に加え、パレットの青の問い合わせと応答を扱う。
- 保存から表示更新までの時間を計測する。
- WIP のアニメーションが表示領域全体を再送せず小さな画像だけを送ることと、完了への変更で更新が止まることを確認する。
- 終了時に文書本体とアニメーションの画像 ID がすべて削除されることを確認する。
- `q`、`Ctrl-C`、`SIGTERM` で終了し、画像削除、カーソル、代替画面、termios の復元を確認する。
- Kitty の対応を確認できない端末では終了コード `1` を返し、同様に端末を復元する。

macOS は canonical mode の復元時に一時フラグ `PENDIN` を設定するため、termios の比較ではそのフラグだけを除外する。

## Rex 上での確認

```bash
make smoke-rex
```

Rex 内の端末から実行する。
一時ファイルと専用の状態ディレクトリを使い、テスト用の分割ペインだけを作成する。
終了時にはそのペインを閉じる。

- 日本語、空白、引用符、シェルの特殊文字を含むパスを渡す。
- 3 回同時に `view` を実行し、同じペイン ID が返ることを確認する。
- 分割時にフォーカスが変わらないことを確認する。
- 倍率 `1.2` で起動し、異なる倍率で再実行しても既存ペインと表示を維持することを確認する。
- 同じサイズと更新時刻での書き換え、削除、rename による再作成を確認する。
- 末尾へのスクロールと、`hide` の再実行を確認する。
- 100 KiB 未満の文書で保存から表示更新までの時間を計測する。

ネットワーク切断などで後処理に失敗した場合は、出力されたテスト用ペイン ID を確認して、そのペインだけを閉じる。

## Rex のリンク入力エンコーダーの確認

```bash
make smoke-links-rex
```

Rex アプリが接続されたセッションで実行する。
一時的に Go のテスト実行ファイルをビルドし、記録用のブラウザ起動関数を持つ Viewer を倍率 `1.2` で Rex の分割ペインに表示する。
起動直後の仮サイズをクリック座標に使わないよう、端末サイズの安定と再描画を待ち、現在のサイズでクリック座標を計算する。
`block.event` API から Cmd キーの押下と解放、マウスの押下と解放を送り、Rex の入力エンコーダーを経由して Viewer へ届ける。
通常クリックでは開かず、Cmd の状態を受け取ったクリックでは異なるリンク先を区別することと、終了時にペインが閉じることを確認する。
テスト用ペインとビルドした実行ファイルは終了時に削除する。
実際のブラウザは起動しない。

このテストは macOS アプリによる物理的なキーとマウスの入力処理を通らない。
実際の Cmd＋クリックやブラウザ起動の確認には、次の手動確認が必要となる。

## 外部リンクの手動確認

```bash
make build
./bin/rex-md-viewer view testdata/links.md
# 分割表示を閉じてから、現在の端末でも確認する
./bin/rex-md-viewer hide testdata/links.md
./bin/rex-md-viewer view --in-place testdata/links.md
```

1. Viewer にフォーカスを移し、Cmd を押しながら文字リンクを左クリックして、既定のブラウザが開くことを確認する。
   リンク A のクエリとフラグメント、リンク B の参照形式のリンク先を確認する。
2. 通常クリック、ドラッグ、余白、ヘッダー、ステータス領域、文書末尾の対象外の記法ではリンクを開かないことを確認する。
3. ペインを狭めてリンクを折り返し、各行から同じリンク先を開くことと、小さな隣接リンクでクリック先を取り違えないことを確認する。
   太字、インラインコード、引用、TODO、表のリンクも確認する。
4. Cmd を離した後や別のペインから戻った後、通常クリックでブラウザが開かないことを確認する。
5. リンクの変更と削除、スクロール、リサイズ、テーマ変更の後に、表示中のリンクとクリック先が一致することを確認する。
6. ブラウザを開いても Viewer が終了せず表示位置を維持することと、`q` で終了した後に端末の通常操作ができることを確認する。

macOS の Rex で、実際の Cmd＋クリックによる文字リンクからのブラウザ起動を利用者が確認済み。
この確認は上記の手動確認項目すべての完了を意味せず、API 経由のスモークテストも手動確認を代替しない。

## 見た目の確認

```bash
./bin/rex-md-viewer render --theme light -o /tmp/rex-md-light.png testdata/sample.md
./bin/rex-md-viewer render --theme dark -o /tmp/rex-md-dark.png testdata/sample.md
./bin/rex-md-viewer view testdata/sample.md
```

見出しの階層、余白、日本語の字形、入れ子のリスト、引用、コード、表の配置、画像の縦横比を確認する。
コードブロックでは Go、Python、Bash のキーワード、コメント、文字列、数値の色分けと、ライトとダークの両方での読みやすさを確認する。
Viewer のペインを狭くし、折り返しとスクロール時の表示崩れを確認する。
プレビューを閉じる際は `rex-md-viewer hide testdata/sample.md` を使用する。

## 確認範囲と制限

開発環境では macOS の Rex、Go 1.27.3、既定の SF Pro Text と日本語フォールバック、および明示指定の外部フォントで描画と実機スモークテストを確認する。
Linux 向けの CI は用意するが、Linux の Rex の実機確認は初期版の完了条件に含めない。
その他の Kitty 対応端末での動作は保証しない。

見た目の確認は自動テストだけで置き換えない。
大規模な画像の連続送信による端末側のメモリ使用量と、別端末から同じセッションを閲覧する場合の見え方は、継続して確認する。
