# 検証手順

## 自動テスト

```bash
make check test
```

Go のテストで以下を検証する。

- CLI の既定値、排他的なオプション、値の検証、`--` 以降のパス。
- フォントの優先順（CLI、環境変数、既定候補、同梱 Go フォント）、読み込み失敗時のフォールバック、相対パスの解決。
- 日本語の文字単位のフォールバック、本文と太字の独立した選択、選択済みフォント設定の分割先への引き継ぎ。
- Skill の埋め込み内容、配置、再実行、上書きの拒否と `--force`。
- 同じサイズと更新時刻での変更検知、rename による置換、削除と復旧、シンボリックリンクの差し替え。
- 連続変更の待機時間と最大待機時間。
- Markdown の対応要素、日本語、コードの空白、狭い幅、表、ローカル画像、GIF の先頭フレーム、画像の読み込み失敗。
- リストのマーカーと本文の間隔、チェックボックスの左位置、入れ子、複数桁の番号、折り返しと後続段落の配置。
- TODO の角丸、チェックマーク、完了本文の色、専用の文字サイズと行間、通常のリストを変更しないこと。
- TODO の装飾と子項目の状態の維持、チェックボックスのスクロール時の切り取り、明るいアクセント色でのコントラスト。
- リモート画像を取得しないこと、HTML をソースとして表示すること。
- 文書全体の画像と、同じ範囲だけを描画した画像の一致。
- 入力 Markdown と同じファイル、ハードリンク、シンボリックリンクへの PNG 出力の拒否。
- 分割表示の同時起動と再利用、終了、別のプログラムを閉じないこと。
- Rex CLI の接続失敗時に状態を失わないことと、split の応答失敗時の起動済みペインの回収。
- Kitty の画像送信と配置、分割されて届く端末応答、色の解析、端末制御文字の除去。

ペイン管理の Go テストは Rex CLI をテスト用プロセスに置き換えて実行する。
実際の Rex との連携は別のスモークテストで確認する。
描画テストは日本語フォントがない場合にスキップするため、テストログを確認する。
CI では Linux に Noto Sans CJK を導入し、macOS ではシステムフォントを使用する。

## 疑似端末での確認

```bash
make smoke
```

Python 3 の標準ライブラリで疑似端末を作り、ビルドしたバイナリを実行する。
Rex は必要ないが、日本語フォントは必要とする。

- Kitty の問い合わせに応答して表示を開始し、送信された PNG が文書全体ではなく表示領域の大きさであることを確認する。
- TODO を含む文書でリサイズ、スクロール、Markdown の変更、削除、再作成、手動更新、テーマ変更を実行する。
- 端末の前景色と背景色に加え、パレットの青の問い合わせと応答を扱う。
- 保存から表示更新までの時間を計測する。
- `q`、`Ctrl-C`、`SIGTERM` で終了し、画像削除、カーソル、代替画面、termios の復元を確認する。
- Kitty の対応を確認できない端末では終了コード `1` を返し、同様に端末を復元する。

macOS は canonical mode の復元時に一時フラグ `PENDIN` を設定するため、termios の比較ではそのフラグだけを除外する。

## Rex 上での確認

```bash
make smoke-rex
```

Rex 内の端末から実行する。
一時ファイルと専用の状態ディレクトリを使い、テスト用の分割ペインだけを作成する。
終了時にはそのペインを閉じる。

- 日本語、空白、引用符、シェルの特殊文字を含むパスを渡す。
- 3 回同時に `view` を実行し、同じペイン ID が返ることを確認する。
- 分割時にフォーカスが変わらないことを確認する。
- 同じサイズと更新時刻での書き換え、削除、rename による再作成を確認する。
- 末尾へのスクロールと、`hide` の再実行を確認する。
- 100 KiB 未満の文書で保存から表示更新までの時間を計測する。

ネットワーク切断などで後処理に失敗した場合は、出力されたテスト用ペイン ID を確認して、そのペインだけを閉じる。

## 見た目の確認

```bash
./bin/rex-md-viewer render --theme light -o /tmp/rex-md-light.png testdata/sample.md
./bin/rex-md-viewer render --theme dark -o /tmp/rex-md-dark.png testdata/sample.md
./bin/rex-md-viewer view testdata/sample.md
```

見出しの階層、余白、日本語の字形、入れ子のリスト、引用、コード、表の配置、画像の縦横比を確認する。
Viewer のペインを狭くし、折り返しとスクロール時の表示崩れを確認する。
プレビューを閉じる際は `rex-md-viewer hide testdata/sample.md` を使用する。

## 確認範囲と制限

開発環境では macOS の Rex、Go 1.27.3、既定の SF Pro Text と日本語フォールバック、および明示指定の外部フォントで描画と実機スモークテストを確認する。
Linux 向けの CI は用意するが、Linux の Rex の実機確認は初期版の完了条件に含めない。
その他の Kitty 対応端末での動作は保証しない。

見た目の確認は自動テストだけで置き換えない。
大規模な画像の連続送信による端末側のメモリ使用量と、別端末から同じセッションを閲覧する場合の見え方は、継続して確認する。
